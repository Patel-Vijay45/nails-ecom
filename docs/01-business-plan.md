# 1. Business Plan

## 1.1 What we sell

Press-on nails are the best product to sell online for a nail artist: they are light, cheap to ship, don't need the customer to visit a salon, and show off the artist's designs.

| Product | Description | Why |
|---------|-------------|-----|
| **Ready-made sets** | 10–12 designs, made in standard sizes (XS, S, M, L). 24 nails per box (extra sizes). | Easy to stock and sell. Best for first-time buyers. |
| **Made-to-measure sets** | Same designs, made to the customer's exact nail sizes. | Higher price, better fit, fewer complaints. |
| **Custom design sets** | Customer sends an idea or photo (wedding, party, festival). Artist designs it. | Highest price. Builds the brand. |
| **Sizing kit** | Blank tips in all sizes so the customer can find their size. Price is refunded as a coupon on the first set. | Removes the #1 problem with press-ons: wrong fit. |
| **Add-ons** | Nail glue, adhesive tabs, file, cuticle stick, prep pad, removal oil. | Raises order value. Every set should include a basic kit. |
| **Later: salon booking** | Book the artist for in-person nail art (if she has a studio/home service). | Uses the same website and customers. |

### Collections to start with (keep it small)

- **Everyday** – nude, French, minimal (best sellers in most stores)
- **Party / Glam** – chrome, glitter, 3D charms
- **Bridal & Festive** – wedding, Diwali, Karwa Chauth, Eid, Christmas
- **Seasonal drops** – 3–5 new designs every month, limited quantity ("drops" create urgency)

Start with **10–15 designs**, not 100. Add more based on what sells.

## 1.2 Pricing (example — adjust after the first 20 orders)

| Item | Cost to make (estimate) | Selling price | Margin |
|------|-------------------------|---------------|--------|
| Ready-made set (simple) | ₹120–200 | ₹499–799 | ~65–75% |
| Ready-made set (glam/3D) | ₹200–350 | ₹899–1,299 | ~65–75% |
| Made-to-measure set | ₹200–350 | ₹999–1,799 | ~70% |
| Custom / bridal set | ₹300–600 | ₹1,999–3,999 | ~75% |
| Sizing kit | ₹40–60 | ₹99–149 (refunded as coupon) | break-even |

**Cost to make** = tips + gel/polish + charms + glue/tabs + box + labour time. Track the artist's time: if a glam set takes 2 hours, price it so that time is paid.

**Per-order extra costs** to plan for:
- Shipping: ~₹50–90 per order (courier aggregator rates)
- Payment gateway: ~2% of order value
- Packaging: ~₹30–60 (box, tissue, sticker, thank-you card)
- Cash-on-delivery returns (RTO): budget 10–20% of COD orders being returned unpaid

**Rules that protect profit:**
- Free shipping above a threshold (e.g. ₹999) to push people to buy 2 sets.
- Prepaid orders get a small discount (e.g. 5%) or COD has a small fee (e.g. ₹49). COD returns are the biggest hidden loss for small Indian stores.
- Bundles: "Any 3 sets for ₹1,999".

## 1.3 Brand

- **Name** – short, easy to spell, `.in`/`.com` domain and Instagram handle available.
- **Story** – "Handmade by a real nail artist" is the selling point. Show her face, her hands, her process.
- **Look** – one colour palette, one font, consistent product photos (same background and lighting).
- **Packaging** – a nice box is part of the product. Customers post unboxings, which is free marketing.

## 1.4 Legal and admin setup (India)

> Check these with a local CA before launch — rules change.

- [ ] Business bank account (or a separate personal account to start)
- [ ] Udyam (MSME) registration — free, useful for later
- [ ] GST registration — ask a CA whether you need it now (depends on turnover, inter-state sales, and whether you sell on marketplaces like Amazon/Meesho, which usually require it)
- [ ] Payment gateway account (Razorpay / Cashfree / PhonePe PG) — needs PAN, bank account, and website policy pages
- [ ] Website policy pages: Privacy, Terms, Shipping, Returns & Refunds, Contact (payment gateways check for these)
- [ ] Product labels: list materials and glue ingredients; add safety notes (patch test, not for damaged nails)

## 1.5 Sales channels

| Channel | When | Notes |
|---------|------|-------|
| Instagram + WhatsApp Business | **Day 1** | Catalogue on WhatsApp, payment links, Instagram shop posts. Fastest way to get first sales. |
| Own website | **Week 5+** | Main store. Best margins, own customer data, no marketplace fees. |
| Marketplaces (Amazon, Meesho, Nykaa, Etsy for export) | **Month 4+** | More reach, but fees and price competition. Only after the product and packaging are proven. |
| Local pop-ups / exhibitions | Any time | Good for bridal leads and for collecting Instagram followers. |

## 1.6 Marketing plan

**Content (Instagram Reels / YouTube Shorts) — the main engine.** Aim for 1 Reel a day for the first 90 days. Ideas:
- Time-lapse of a set being made
- "Applying press-ons in 5 minutes" tutorial
- Before / after hand shots
- Unboxing a customer order
- "Which set should I wear to …?" polls
- Behind the scenes of the artist

**Other tactics:**
- Collaborate with 5–10 small creators (5k–50k followers): send a free set in exchange for a Reel.
- Ask every customer for a photo review; offer ₹100 off the next order for it.
- WhatsApp broadcast list for new drops and festival offers.
- Bridal: partner with makeup artists, mehndi artists, and wedding planners for referrals.
- Paid ads (Meta) only after you know which designs sell; start small (₹300–500/day) and promote the best Reels.

## 1.7 Numbers to track every week

| Metric | Why |
|--------|-----|
| Orders and revenue | Are we growing? |
| Average order value | Are bundles/add-ons working? |
| Repeat customer % | Do people come back? (target 25%+) |
| Wrong-size complaints | Is the sizing guide/kit working? |
| COD return rate | Is COD costing money? |
| Best-selling designs | Make more of these |
| Instagram followers & Reel views | Is marketing working? |

## 1.8 90-day roadmap

### Weeks 1–4: Validate (no website yet)
- [ ] Pick brand name, register Instagram + WhatsApp Business + domain
- [ ] Make 10–15 designs; photograph each one the same way
- [ ] Make the sizing kit and a sizing guide (photo + video)
- [ ] Order packaging (boxes, stickers, thank-you cards, mini prep kits)
- [ ] Set up Razorpay/UPI payment links and a courier account (e.g. Shiprocket)
- [ ] Post daily; take orders on WhatsApp
- [ ] **Goal: 20 paid orders, learn the top 5 designs**

### Weeks 5–8: Launch the store
- [ ] Build the website (see [Website build plan](03-website-build-plan.md))
- [ ] Add policies, sizing guide, reviews from the first customers
- [ ] Move WhatsApp customers to the website with a launch coupon
- [ ] **Goal: 50 orders/month, 30%+ from the website**

### Weeks 9–12: Grow
- [ ] Creator collaborations
- [ ] Monthly design drops
- [ ] Bundle and repeat-customer offers
- [ ] Start small Meta ads on the best-performing Reels
- [ ] Open custom/bridal orders with a deposit
- [ ] **Goal: 100+ orders/month, 25% repeat customers**

## 1.9 Main risks and how to handle them

| Risk | Fix |
|------|-----|
| Wrong size → returns and bad reviews | Sizing kit, clear guide, extra sizes in every box, made-to-measure option |
| The artist can only make so many sets | Batch-produce ready-made designs; keep custom slots limited; later hire/train a helper for simple sets |
| COD orders returned unpaid | Prepaid discount, COD fee, confirm COD orders on WhatsApp before shipping |
| Designs copied by others | Post consistently, build the personal brand; the artist's face and story can't be copied |
| Broken nails in transit | Sturdy box, nails fixed on a card, bubble wrap |
